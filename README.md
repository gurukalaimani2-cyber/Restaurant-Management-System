# Restaurant Management System - Module 1

Production-grade Spring Boot application implementing **Login Authentication**, **Dashboard**, and **Logout** using Java 17, Spring Boot, Spring Security, Spring Data JPA, MySQL, and Thymeleaf with Bootstrap 5.

## Features

- Secure login with Spring Security (BCrypt password hashing)
- Session-based authentication with CSRF protection
- Professional, responsive Dashboard
- Navigation menu (Dashboard + Logout functional; all other modules show "Coming Soon")
- Secure logout that invalidates the session
- Unauthenticated users are always redirected to `/login`

## Technology Stack

- Java 17
- Spring Boot 3.2.5
- Maven
- MySQL 8
- Spring Security
- Spring Data JPA (Hibernate)
- Thymeleaf + Thymeleaf Spring Security extras
- Bootstrap 5
- HTML5 / CSS3 / JavaScript
